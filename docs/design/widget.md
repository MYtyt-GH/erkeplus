# 桌面小组件

目标：**桌面上就能看到课表**，点一下进课表页。课表是最常看的一页，值得常驻桌面。

技术选型见 [ADR 0006](../decisions/0006-widget.md)；状态按「已做 / 待做」标。

## 一、三种组件

| 组件 | 内容 | 字号 | 状态 |
| --- | --- | --- | --- |
| 课程看板 | 一天，一行一节课：时间 · 课名 · 教室 | 课名 17sp（最大） | 已做 |
| 最近两节课 | 只看接下来最近的两节（跨天也算） | 课名 18sp | 已做 |
| 半天课表 | 当前阶段（上午/下午/晚上）的课，没课就顺延 | 课名 15sp | 已做 |
| 活动待办 | 报名截止、签到开始、待处理消息 | — | 待做，依赖 [notifications.md](../plan/notifications.md) M1 |
| 活动看板 | 最新活动 / 我报名的活动 | — | 待做，依赖活动列表落盘 |

三种组件共用同一份数据与同一套地基；差别只有「取哪几条课 + 多大字 + 什么布局」。

**为什么课程看板是一天**：试过整周网格（七列）——手机上每列只有 40dp，字必须压到 8sp，
还塞不下时间与教室；也试过两列两天——每列课名只剩 4~5 个字。最后定为一天三列
（时间 / 课名 / 教室），字号能提上来，信息也齐。

## 二、地基

```
ui/widget/
  BaseWidgetProvider.kt     抽象基类：onUpdate / onAppWidgetOptionsChanged / 系统广播 → 渲染
  WidgetRefresh.kt          写缓存或改外观后主动推一次（不等系统定时）
  WidgetIntents.kt          深链：点组件 → 课表页
  WidgetAppearance.kt       外观：背景色、透明度、文字色、字号（用户可调）
  WidgetText.kt             每个文本控件的基准字号与主/次色归类
  WidgetSizing.kt           高度 × 字号 → 行数；宽度 → 是否窄档    [纯函数]
  WidgetData.kt             读缓存 + 别名 → 学期、课、今天、现在
  WidgetViews.kt            三种组件共用的行/背景画法
  WidgetRegistry.kt         组件清单（「更多」里的添加入口读它）
  board/ recent/ halfday/   各自的纯 Model + Provider
```

**加一类组件要做的六件事**：写纯 Model → 写 layout 与 Renderer → 继承 `BaseWidgetProvider`
→ 在 `WidgetRegistry` 登记 → 清单注册 receiver 与 appwidget 元数据 → 在写缓存的地方补 `WidgetRefresh`。

## 三、数据

只读缓存，不发请求（见 [oem-compat.md](oem-compat.md)）：

- 课表页每次刷新成功、切周成功都写缓存，写完立刻推一次组件；
- 日期 / 时间 / 时区 / 语言变化、放置、改尺寸、开机后由系统广播触发重画；
- 课表页刷新成功后**顺带预取下一周**，避免周一早上桌面空着；
- 组件里显示的课名优先用**用户起的别名**（`CourseAliases`，入口在课表页的课程详情里）。

## 四、时间语义

### 4.1 阶段划分

按官方作息表的节次切：上午 1–4 节（08:00–11:40）、下午 5–8 节（14:00–17:40）、
晚上 9–12 节（17:50–21:20）。「现在处于哪个阶段」按钟点：< 12:00 上午，< 18:00 下午，其余晚上。

### 4.2 课程看板画哪一天

1. 今天有课（不管上没上完）→ 画今天，已上完的调暗；
2. 今天没课 → 往后找第一个有课的日子，头部写「明天 11/14」；
3. 都没有 → 「今天没有课程」+「这周剩下的时间没课」。

### 4.3 最近两节课取哪两节

从「现在」往后取两节，正在上的算第一，跨天跨周都算（有缓存才看得到）。

### 4.4 半天课表取哪个阶段

用户的规则：当前阶段有课就用当前阶段，没有就看下一阶段，依次往后，都没有就写「暂无半天课表」。
实现上把「有课」收紧为**「还有没上完的课」**：11:50 时上午刚下课，再画上午等于把桌面停在过去。
候选序列：今天当前阶段 → 今天晚上 → 明天上午 → …，只走有缓存的日子。

窄档位（< 200dp）只留课名与状态，藏掉教室那一列。

### 5.4 字号与颜色

| 元素 | 看板 | 最近两节 | 半天 |
| --- | --- | --- | --- |
| 顶部周次 / 日期 | 12sp / 11sp | — | — |
| 标题（接下来 / 阶段） | — | 11sp | 15sp |
| 时间 | 12sp（46dp 一列，最多两行） | 12sp（在第二行） | 12sp（在第二行） |
| 课名 | 17sp | 18sp | 15sp |
| 教室 | 14sp（右侧一列） | 14sp（在第二行） | 12sp（在第二行） |
| 圆点 | 7dp | 9dp | 8dp |

**基准字号只有一份**：`WidgetText` 里的这张表。布局 XML 的 `textSize` 只是「没套外观时的兜底」，
套了外观（标准档也算）就按表重写一遍。以前标准档走 XML、大小档走表，两套基准漂移过一次，
表现就是点「大」跟没点一样——现在标准档也显式写，并用 `WidgetScaleTest` 守着「小 < 标准 < 大」。

颜色全部来自 `values{,-night}` 资源（跟随系统深浅色）：`widget_surface` / `widget_text` /
`widget_text_secondary` / `widget_accent` / `widget_row_now` / `widget_row_past`，以及课程色
`course_color_1..8`（圆点，与课表页的课程块同一套，`ui/CourseColor.kt`）。

**状态只用底图表达，不用绝对色值改文字颜色**：把颜色「烤」进 RemoteViews 后，
用户切深色模式，桌面会停在旧主题的色值上（深字压深底）。

### 5.5 圆角

背景是运行时画的圆角位图（RemoteViews 没法给任意颜色的圆角图形）：

- 圆角 16dp、内容内边距 14dp——半径比留白大时，顶部那行日期会压进弧线，看着像跑到卡片外面；
- 位图尺寸取系统报的 dp 尺寸，改尺寸时会重新画。

## 六、外观交给用户调（「更多 → 桌面小组件」）

壁纸千差万别，与其替用户猜一种底色，不如把四件事交出去（参考番茄 Todo 的做法）：

| 设置 | 取值 | 默认 |
| --- | --- | --- |
| 背景色 | 跟随主题 + 8 个预设色 | 跟随主题 |
| 背景透明度 | 0%–100% | 100%（不透明） |
| 文字颜色 | 跟随主题 + 5 个预设色 | 跟随主题 |
| 文字大小 | 小 90% / 标准 100% / 大 135% | 标准 |

「标准」就是基准字号本身，三档的倍数都相对它算。大从 115% 提到 135%（2026-11-15）：
原来的 15% 在桌面上几乎看不出差别，用户反馈「大没有标准大」。

改完立刻推一次组件，桌面上的组件马上跟着变。

**添加入口也在这里**：国产 ROM 把「添加小部件」藏得很深（长按桌面 → 编辑 → 小部件 → 找应用），
所以「更多 → 桌面小组件」先替用户调起系统的「固定到桌面」，调不起来或桌面没反应，
再给出明确的手动路径（长按桌面空白处 → 小组件 → 二课++）。

## 七、交互

| 位置 | 行为 |
| --- | --- |
| 整块 / 任意行 | 打开「我的课表」页（深链 `open=timetable`） |
| 从课表页返回 | 回到主界面（发现页）：应用默认就在这一页，不用额外写代码 |
| 长按 | 交给系统的组件菜单 |

## 八、刷新策略

| 事件 | 谁触发 |
| --- | --- |
| 课表缓存写入 / 别名修改 / 外观修改 | 应用内主动 `WidgetRefresh` |
| 日期变更、改时间/时区/语言 | 系统广播 |
| 放置、改尺寸、开机、应用更新 | 系统 `onUpdate` |
| 兜底 | `updatePeriodMillis = 30 分钟` |

不申请任何新权限。

## 九、验收

浅色 / 深色 × 自定义颜色各看一遍；尺寸 2×2、4×2、4×4；系统字号 1.0 / 1.3 / 1.5；
状态：没登录 / 开学前 / 放假 / 这周没下载 / 今天有课 / 今天没课 / 今天上完了 / 正在上。

真机主验 24090RA29C。组件预览页（debug 包）：
`am start -n gitee.leolin_me.erkepp.debug/gitee.leolin_me.erkepp.debug.WidgetPreviewActivity --es which board --ei width 320 --ei height 170`

## 十、未验证与风险

| 项 | 影响 | 兜底 |
| --- | --- | --- |
| 各桌面给组件的内边距不同 | 边缘留白略不同 | 主验机型上看；内边距交给系统 |
| 深色模式切换时组件是否重画 | 文字颜色是资源、跟随系统；自定义色是绝对值 | 自定义色本来就是用户选择 |
| 系统「固定到桌面」在个别 ROM 上静默失败 | 用户点了没反应 | 两秒后检查有没有真加上，没加上给手动路径 |
| 整学期一次拉全是否可行 | 跨周空窗 | 先用「预取下一周」 |
